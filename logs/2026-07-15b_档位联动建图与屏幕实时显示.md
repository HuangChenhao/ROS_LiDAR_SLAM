# 2026-07-15 工作日志(下) — 档位联动建图 + 屏幕实时显示

## 1. 核心架构改变：档位驱动的 SLAM 生命周期

新增 **slam_supervisor** 常驻节点（容器内），由手柄状态自动管理建图：

| 状态 | 雷达 | 建图 | 屏幕 |
|---|---|---|---|
| 红灯（未激活/开机默认） | **停转**（DTR 拉高） | 无 | 正常熄屏 |
| 激活（任意档位 1/2/3） | 运转 | 进行中 | **全屏实时地图 + 常亮** |

- joy_ctrl 发布 `/MappingState`（transient_local）：`Joy_active` 即为 true
- 会话文件夹以**扫描开始时间**命名：`/root/rosmaster_maps/<YYYYmmdd_HHMMSS>/`
- 结束条件：切红灯 / 硬关机（每30秒自动存档，最多丢30秒）
- 开机默认红灯不建图 → 远程调试不产生垃圾数据

> 中途调整：原设计3档不建图，因档位误触发问题改为"激活即建图"，档位只区分速度。

## 2. 雷达马达停转（DTR 控制）

A1 马达由串口 DTR 控制，无节点管理时默认常转。supervisor 在非建图期占住 `/dev/rplidar` 并拉高 DTR（马达停），建图前释放给 sllidar_node。皮带结构无需改动。

**踩坑**：supervisor 重启时旧 sllidar/gmapping 孤儿进程抢串口 → 启动时先 pkill 清理。

## 3. 屏幕实时显示（map_kiosk.py）

Pi host 常驻（用户 pi，XWayland + tkinter）：
- 每 0.5s `docker cp` 拉取 `live_preview.pgm`（supervisor 收到新 /map 才重绘，跟随 gmapping 节奏）
- 预览存在 → 全屏窗口显示地图；消失 → 隐藏
- **常亮**：临时把 wayfire.ini `[idle] dpms_timeout` 改为 -1（wayfire 热加载），结束自动恢复
